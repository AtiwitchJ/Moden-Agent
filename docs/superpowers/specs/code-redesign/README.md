# Code Redesign

เริ่มออกแบบโครงใหม่จากหน้า Code ก่อน แล้วจึงต่อไปยัง Director และ Work

- `brief.md` — เป้าหมาย, layout และ flow ของหน้า Code
- `code-manage.md` — เป้าหมาย, layout และ flow ของหน้า Director
- `work.md` — เป้าหมาย, layout และ flow ของหน้า Modern Work
- `project-sessions.md` — แผน shared topology: หนึ่ง project และหลาย sessions
- `wireframes/` — ภาพหรือ wireframe ที่ผ่านการเลือกแล้ว
- `decisions.md` — ข้อตัดสินใจที่ล็อกก่อนเริ่ม implementation
