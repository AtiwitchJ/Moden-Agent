# 3-Mode Shell + Moden Code Manage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split the app into three top-level modes — **Code** (existing project/session shell), **Code Manage** (the existing global Workboard as its own mode), **Work** (placeholder) — switched by a new ModeBar strip at the very top of the window, above the current titlebar/topbar.

**Architecture:** Route-prefix per mode (approved option A). The URL is the source of truth for the active mode: `/manage/*` = Code Manage, `/work` = Work, everything else = Code. `__root.tsx` gains a persistent `ModeBar` above the `<Outlet>`; each mode keeps its own shell below it. Code Manage uses a light shell (ModeBar + full-bleed `<Workboard />`, no project sidebar — approved option ก). No backend/daemon changes; Workboard keeps using its existing API and components unchanged.

**Tech Stack:** React 19, TanStack Router (file-based routes, hash history, `@tanstack/router-plugin` regenerates `routeTree.gen.ts` automatically on dev/build/test), TanStack Query, shadcn primitives, Electron (`hiddenInset` titlebar), Vitest + Testing Library.

## Global Constraints

- No backend/daemon changes. Frontend renderer only, plus one 2-line tweak in `frontend/src/main.ts` (traffic-light position).
- Follow DESIGN.md: renderer clones modern-agent verbatim; build new UI from shadcn primitives where a component fits; refined-blue accent.
- Do not hand-edit `frontend/src/renderer/routeTree.gen.ts` — it is generated by `TanStackRouterVite` when Vite runs (`npm run dev`, `npm run test`, `npm run typecheck` after a dev/test run has regenerated it).
- Hash history (`createHashHistory`) — all navigation stays client-side; no server routes involved.
- Mode names in UI copy, verbatim: `Code`, `Code Manage`, `Work`.
- App state stays under `~/.ao` (untouched by this plan).
- All existing tests must keep passing: `cd frontend && npm run typecheck && npm run test`.

## Locked product decisions (from brainstorm)

- ModeBar is the topmost strip (~40px), above the existing 56px ShellTopbar. It hosts the macOS traffic-light inset and the fixed TitlebarNav cluster (sidebar toggle + back/forward), and the three mode tabs.
- Modes operate independently; switching modes = navigation.
- Code Manage is a light shell: ModeBar + `<Workboard />` full-bleed. No project sidebar, no ShellTopbar.
- `/workboard` redirects to `/manage` (old deep links keep working).
- The root `/` no longer force-redirects to the workboard. Code mode's home is the CEO Dashboard again (`_shell.index.tsx` renders it already; only the redirect goes away). Workboard-as-home moves to the Code Manage mode.
- Work mode is a single placeholder page. No spec yet; do not build features there.

```tsx
// frontend/src/renderer/components/ModeBar.tsx
import { useNavigate, useRouterState } from "@tanstack/react-router";
import { cn } from "../lib/utils";

const isMac = typeof navigator !== "undefined" && /Mac|iPod|iPhone|iPad/.test(navigator.userAgent);
const dragStyle = isMac ? ({ WebkitAppRegion: "drag" } as React.CSSProperties) : undefined;
const noDragStyle = isMac ? ({ WebkitAppRegion: "no-drag" } as React.CSSProperties) : undefined;

export type AppMode = "code" | "manage" | "work";

export function activeModeFromPathname(pathname: string): AppMode {
	if (pathname === "/manage" || pathname.startsWith("/manage/")) return "manage";
	if (pathname === "/work" || pathname.startsWith("/work/")) return "work";
	return "code";
}

const MODES: { id: AppMode; label: string; to: string }[] = [
	{ id: "code", label: "Code", to: "/" },
	{ id: "manage", label: "Code Manage", to: "/manage" },
	{ id: "work", label: "Work", to: "/work" },
];

// Topmost window strip: hosts the macOS traffic-light inset (left 79px, same
// as the TitlebarNav cluster budget) and the three mode tabs. The whole strip
// is a drag region; tabs punch no-drag holes. TitlebarNav (fixed, top-left)
// overlays this strip — see .titlebar-nav in styles.css (height 40px).
export function ModeBar() {
	const navigate = useNavigate();
	const pathname = useRouterState({ select: (state) => state.location.pathname });
	const active = activeModeFromPathname(pathname);

	return (
		<div
			className={cn(
				"flex h-10 shrink-0 items-center justify-center border-b border-border bg-background",
				isMac && "pl-[167px] pr-4", // traffic lights + TitlebarNav cluster live in this inset
			)}
			style={dragStyle}
		>
			<div className="flex items-center gap-1 rounded-lg bg-interactive-hover/50 p-0.5" style={noDragStyle}>
				{MODES.map((mode) => (
					<button
						key={mode.id}
						aria-current={active === mode.id ? "page" : undefined}
						className={cn(
							"rounded-md px-3 py-1 text-[12px] font-medium transition-colors",
							active === mode.id
								? "bg-interactive-active text-foreground"
								: "text-passive hover:bg-interactive-hover hover:text-foreground",
						)}
						onClick={() => void navigate({ to: mode.to })}
						type="button"
					>
						{mode.label}
					</button>
				))}
			</div>
		</div>
	);
}
```
